# QuickMaths formal verifier — isolated educational proof assistant

This directory implements the theorem-prover trust boundary described in `docs/THEOREM_PROVER_ROADMAP.md`. QuickMaths owns the educational statement/proof model; Lean 4 + mathlib check the generated proof artifacts. Opt-in formal questions use this verifier for assessment, while ordinary questions retain their existing grading.

## What exists now

- strict, versioned typed request contract with stable variable IDs and scoped proof nodes;
- an exact school-notation parser that rejects undeclared identifiers, approximate decimals and ambiguous integer division while accepting common input forms such as Unicode powers, absolute-value bars, natural-language quantifiers, bounded interval universals such as `for every t:real in [0,1], ...`, and explicit piecewise `if … then … else …`;
- canonical human-readable statement previews;
- first-class domain requirements for division, school-real square root and school-real logarithm;
- an obligation graph that rejects later references, scope leakage, uncited side conditions and a final goal that was never established;
- a curated educational rule registry for algebra, equations, sign-aware inequalities and natural-deduction proof structure;
- scoped implication/negation introduction, case splits, witnesses, quantifiers and natural-number induction;
- function/set reasoning through extensionality, membership and subset rules;
- bounded, untrusted candidate search using exact symbolic reasoning where useful, including a conservative affine entailment gate before proposing `linarith`;
- deterministic Lean source generation that clears uncited proof nodes before each learner step;
- finite/directed limit rules for removable rational holes, conjugate holes, reciprocal one-sided infinities and exact piecewise jumps;
- a JSON/RPC protocol, constrained text-authoring helper and loopback companion HTTP service;
- a manual proof-session API/workbench where learners can add one school-notation step at a time and immediately inspect available assumptions, obligations and kernel readiness;
- bounded Lean execution, axiom auditing and content-bound replayable certificates when the pinned Lean environment is present.

SymPy, local rule checks and search **never issue `verified`**. They can produce candidates, missing obligations or checked counterexamples. Only the Lean verification path can issue a certificate.

## Commands

### Windows pinned setup

From the repository root, run the setup once, then dot-source the environment
in every terminal that uses Lean or the companion. Toolchains, cache downloads
and temporary files stay under `X:\QuickMaths\.bridge-runtime\formal`;
Lake packages/build outputs stay in `X:\QuickMaths\formal-verifier\.lake`.

```powershell
.\scripts\setup-formal.ps1
. .\scripts\formal-env.ps1
cd formal-verifier
lake build QuickMathsFormal
```

The setup uses the committed `lake-manifest.json`, Lean
`leanprover/lean4:v4.34.0-rc2`, and mathlib revision
`42a3845c6d7ec6866eefa4cc327a306a0c4a7d3c`.

```bash
cd formal-verifier
python -m pip install -e '.[dev]'
pytest

# Inspect without claiming proof
qm-formal inspect fixtures/conjugate_limit.json
qm-formal search fixtures/conjugate_limit.json
qm-formal render fixtures/conjugate_limit.json

# Constrained school notation
qm-formal prove-text '(x^2 - 9)/(x - 3) = x + 3' --var x:real --assume 'x != 3'

# Local browser/CLI companion
qm-formal serve --host 127.0.0.1 --port 8765
```

The companion RPC also exposes `new_text_request`, `append_text_step` and `replace_text_step` for stateless interactive proof construction. The native lesson workspace can call `check_progress` for bounded root-prefix checks through the same Lean verifier. Progress certificates have mode `progress` and never stand in for a complete learner submission. Candidate readiness remains distinct from kernel verification. See `../LOCAL_RELEASE.md` for the workspace release, validation limits and continuation notes.

When Lean is unavailable, `check`/`prove` return `verification_unavailable` with the exact deterministic Lean artifact instead of pretending the theorem was proved. A timeout is `search_limit_reached`, never `false`.

The historical source-package checks exercised the unavailable path.
The real pinned integration additionally checks generated fixtures, production
certificates, reference replay, HTTP/store/WebMCP assessment and the native browser

## Current mathematical boundary

Supported candidate/rule families include:

- polynomial and guarded rational identities;
- exact rational point arithmetic can discharge obvious derivative domain guards, while symbolic guards still require explicit cited evidence;
- equality reflexivity, symmetry and transitivity;
- add/subtract/multiply/divide-both-sides with explicit nonzero evidence where required;
- one-way squaring of an equality;
- add-to-inequality and positive/negative inequality scaling with direction checks;
- `sqrt(x^2) = x` under a nonnegative hypothesis and conjugate identities;
- removable rational-hole limits;
- `(sqrt x - c)/(x-c^2)` conjugate-hole limits on `x >= 0` for exact positive rational `c`;
- one-sided `1/x` infinities at zero;
- exact two-branch piecewise jumps with unequal rational branch values;
- pointwise derivatives for polynomial expressions, guarded polynomial quotients and positive-domain square roots;
- `|p(x)|` derivatives away from the zero branch point, with explicit positive/negative evidence;
- `exp(p(x))`, `log(p(x))`, `sin(p(x))` and `cos(p(x))` chain-rule derivatives for polynomial `p`, with `log` restricted to a strictly positive school-real argument;
- a recursive compositional derivative rule over constants/variables, negation, addition, subtraction, multiplication, division, natural powers, square roots, absolute value, `exp`, school-real `log`, `sin` and `cos`; every guarded node contributes an explicit pointwise obligation, and nested absolute values are bounded to prevent branch explosion;
- conservative automatic guard reconstruction for exact rational facts (`norm_num`) and syntax-obvious positive/nonzero facts such as `exp(t)` or `x^2 + 1` (`positivity`). These shortcuts only generate Lean evidence; they never issue certificates themselves;
- a proof-producing structural continuity planner for finite direct-substitution limits over the same safe expression grammar, with pointwise denominator, square-root and school-real logarithm guards reconstructed explicitly;
- a compositional finite-limit algebra planner/reconstructor that builds explicit `Tendsto` trees for constants, the approach variable, arithmetic, natural powers and continuous unary composition; exact-source finite sublimits can be cited as opaque leaves, while quotient/log/sqrt nodes require kernel-reconstructed target guards;
- first-class sequence goals over `Nat.atTop`, with explicit `real(n)` natural-to-real casts, natural-index powers, shifted reciprocal/geometric/compositional limits, exact shifted and affine-over-affine asymptotics, equal-degree quadratic ratios, and general exact rational-coefficient polynomial-ratio asymptotics through degree 64, eventual squeeze evidence with automatic standard sin/cos-over-positive-shift bounds, bounded monotone/antitone existence proofs with automatic exact geometric order evidence, reusable sequence sublimits, elementary oscillation/no-finite-limit classification for nonconstant affine transforms of `(-1)^n`, exact rational-valued modulo-periodic sequences of period 2-4, finite prefixes followed by those exact periodic cores, and those oscillating cores plus one automatically reconstructed finite-convergent perturbation, exact geometric growth classification for `r^n`, and a separate `real(n+k) → +∞` rule;
- first-class infinite-series goals covering exact rational geometric terms `a*r^n`, shifted p-series with exact integer/rational real exponents, cited nonnegative comparison tests, a conservative ratio test from cited global/eventual successive-term bounds `|a_(n+1)| <= r*|a_n|` with exact rational `0 <= r < 1`, and the quotient-limit ratio theorem from an exact sequence limit `|a_(n+1)|/|a_n| -> L`: rational `0 <= L < 1` proves summability with cited eventual nonzero terms or exact kernel-reconstructible polynomial/geometric tail guards, while rational `L > 1` proves non-summability without a separate nonzero premise; a first root test also consumes an exact limit `abs(a_n)^(1/real(n)) -> L`, proving summability for rational `0 <= L < 1` and non-summability for rational `L > 1`, with `L = 1` explicitly inconclusive; exact geometric `r^n` quotient statistics and exact polynomial-geometric quotient statistics can be reconstructed directly after folding products/quotients of nonzero rational geometric factors to one base around a single rational polynomial numerator, and the root statistic can also be reconstructed when exact multiplication/division normalization reduces the term to `(p(real(n))/q(real(n)))*r^n`, including products of rational geometric factors and nonzero rational geometric factors in denominators, with nonzero rational-coefficient `p,q` of degree at most 64; polynomial-geometric terms are the `q=1` special case, and school-domain denominator guards are suppressed only for a conservative global/eventual Nat-nonzero fragment that Lean re-proves explicitly; positive factors use `positivity`, exact nonzero rational geometric powers use `pow_ne_zero`, and exact rational polynomial factors through degree 64 may use a concrete `Nat.atTop` threshold plus an exact shifted-polynomial certificate checked by `ring` and `positivity`; the shared polynomial normalizer also accepts the bound Nat index as bare `n` inside an otherwise real-coercible polynomial factor, so shifted powers such as `(n+1/2)^2` do not require an explicit `real(n)` wrapper in either automatic ratio-limit or root-limit reconstruction; pure integer/integer division remains deliberately ambiguous; broader limit synthesis remains deliberately non-automatic;
- a generalized IVT-existence rule on exact real intervals for structurally continuous expressions whose interval-wide domain guards and endpoint brackets can be proved automatically or cited explicitly; non-automatic interval guards are first-class universal premises, including conservative stronger-to-weaker bridges such as positive ⇒ nonzero.

The current general-proof interaction supports nested scoped subproofs, conjunction/disjunction, implication, contradiction, quantifier introduction/elimination, existential witness scopes, natural-number induction, function extensionality, set extensionality and subset reasoning. Search is intentionally bounded and incomplete; unsupported or unproved goals stay unresolved rather than being labeled false.

The original narrow polynomial IVT rule remains available, and `continuous_ivt_exists` broadens existence proofs to structurally continuous expressions on exact real intervals when interval-wide domain guards and endpoint brackets are reconstructible. Interval guards that are not syntax-obvious may now be supplied as quantified evidence such as `for every t:real in [0,1], t + 2 != 0`; the generated `ContinuousOn` proof instantiates that exact premise at the interval point. Those bounded universal facts can themselves be constructed by the scoped planner using ordinary quantifier/implication introduction plus arithmetic, rather than existing only as lesson-authored assumptions. IVT still proves existence only; uniqueness remains a separate obligation. Recursive differentiation and continuity are deliberately limited to the documented compositional expression grammar: arbitrary declared functions, unsupported special functions, and integrals remain outside these rules rather than being guessed. Piecewise expressions remain explicit-special-case territory rather than being declared continuous by the generic planner.

## Integration boundary

`schemas/formal-proof.schema.json` documents the declarative request shape. The Python contract remains authoritative for semantic validation because JSON Schema cannot enforce variable binding, ancestor scopes, mathematical typing or proof-rule soundness.

The localhost service exposes `/health` and `/v1/rpc`, rejects nonlocal browser origins by default, caps requests at 1 MB, and does not log proof bodies. It is an integration seam, not a production verification badge.

No current lesson mode, mastery calculation, sync record or historical tutor review is converted into kernel certification by this package.

## Real-kernel acceptance gate

The ordinary Python tests intentionally run without Lean so the UI, parser,
scope checker, rule registry, certificate binding and honest unavailable states
remain cheap to exercise.  They are **not** a substitute for kernel checking.

`python scripts/kernel_acceptance.py` is the strict gate for a Lean-capable
environment.  It requires the pinned `lean-toolchain` and mathlib revision,
builds/verifies the advertised acceptance corpus, requires a fresh certificate
for every positive fixture, and confirms that negative fixtures never acquire a
certificate.  The GitHub Actions workflow `.github/workflows/formal-verifier.yml`
runs that gate on formal-verifier pull requests and `codex/**` pushes.

The IVT corpus now includes both the narrow polynomial existence family and
structural-continuity examples such as `1 / (x^2 + 1)` on an exact interval.
Interval-wide domain conditions can now be supplied through first-class quantified evidence when they are not automatically reconstructible. Finite limit algebra can combine previously proved finite sublimits over the exact same source filter with arithmetic and guarded unary composition. Sequence convergence is first-class over `Nat.atTop`: shifted reciprocals, geometric tails and compositional finite limits reconstruct explicit `Tendsto` proofs; exact `real(n+a)/real(n+b)` ratios reduce to reciprocal tails, exact affine-over-affine ratios use mathlib's dedicated Nat.atTop theorem, and exact quadratic-over-quadratic ratios retain their small transparent `n^2` proof; the general polynomial-ratio fallback reconstructs explicit `Polynomial ℝ` values and delegates lower/equal/higher-degree quotient asymptotics to mathlib, with exact rational coefficients and a degree-64 bound; `eventually` bounds are transparent threshold quantifiers consumed by a squeeze rule, while the standard `-1 <= sin/cos <= 1` bounds divided by `real(n+k)`, `k>=1`, can be reconstructed automatically; cited monotone/upper-bounded or antitone/lower-bounded evidence still works, and exact shapes `L - c*r^n` / `L + c*r^n` with `c>0`, `0<=r<=1` can derive the order evidence directly in Lean. Elementary divergence is now first-class too: nonconstant exact affine transforms of `(-1)^n` are proved nonconvergent by incompatible even/odd subsequences; exact rational-valued modulo-periodic expressions with one modulus in `{2,3,4}` are proved nonconvergent from two incompatible residue-class subsequences; a top-level finite prefix of the form `if n < K then PREFIX else CORE` is discarded by an eventual-equality proof before the same residue argument runs; adding or subtracting one common finite tail preserves the separation between those subsequence limits when that tail is either reconstructed by the existing sequence-algebra engine or cited from one earlier exact finite sequence-limit proof (for example `(-1)^n + (2 + 1/real(n+1))`, `(-1)^n + 1/real(n+1)`, or `(-1)^n + real(n)/real(n+1)` after citing the earlier ratio limit); exact `r^n` with `r>1` can be classified as `+∞` or as having no finite limit, and exact `r^n` with `r<-1` is shown to have no finite limit via absolute-value growth. Natural-index casts approaching `+∞` use a distinct rule. Geometric series, shifted p-series with exact integer or rational real exponents, a conservative nonnegative comparison test, the cited ratio-bound test, the quotient-limit ratio test, and a strict n-th-root test are now first-class. The p-series rule supports exact nonzero rational multiples of `1 / real(n+k)^p` with `k >= 1` and exact `0 <= p <= 64`; integer powers use mathlib's natural-power criterion while non-integer rational powers use its real-rpow criterion, and both classify summability exactly by `p > 1`. The comparison rule consumes a cited known summable/nonsummable comparison series plus cited global or eventual nonnegative pointwise domination in the mathematically correct direction; it does not synthesize inequalities. The bound-form ratio rule consumes one cited global or eventual inequality `abs(a(k+1)) <= r * abs(a(k))` with exact rational `0 <= r < 1` and delegates summability to mathlib's `summable_of_ratio_norm_eventually_le`. The quotient-limit rule consumes a cited finite sequence theorem for `abs(a(k+1))/abs(a(k)) -> L`. For exact rational `0 <= L < 1`, it separately requires `a(k) != 0` eventually and now accepts either cited evidence or the same exact rational polynomial/geometric tail certificates used by the root-test domain layer; for exact rational `L > 1`, it proves non-summability through mathlib's divergence theorem, which derives eventual nonzero behavior internally. Exact geometric `r^n` may reconstruct the constant quotient internally. The next automatic ratio family also reconstructs `abs(a_(n+1))/abs(a_n) -> abs(r)` when exact multiplication/division normalization leaves a nonzero rational-polynomial quotient `p(real(n))/q(real(n))`, with both degrees at most 64, together with one or more nonzero exact rational geometric factors. Those geometric factors, including geometric denominator factors, are folded to one exact base `r`; Lean explicitly rebuilds `p(x+1)`, `p(x)`, `q(x+1)`, and `q(x)` as `Polynomial ℝ`, proves `p(x+1)/p(x) -> 1` and `q(x)/q(x+1) -> 1` from equal degrees and leading coefficients, passes both limits through absolute value, combines them, and independently checks the geometric absolute-value normalization with `abs_mul`/`abs_div` and `mul_pow`/`div_pow`. Exact polynomial denominator safety is discharged only through the same kernel-checkable global/eventual tail certificates; non-polynomial denominators and more general quotient limits still require a cited theorem. The exact polynomial classifier accepts both explicit `real(n)` and bare bound `n` in real-coercible sequence/series polynomial syntax; Lean still checks the inserted Nat-to-Real coercions, and integer-only division is not guessed as real division. The boundary `L = 1` remains explicitly inconclusive for both ratio and root tests. The root rule consumes an exact finite sequence theorem for `abs(a(k))^(1/real(k)) -> L`; `0 <= L < 1` yields eventual geometric domination, while `L > 1` contradicts the necessary condition that summable terms tend to zero. Exact products/quotients of rational geometric factors around a polynomial quotient are first normalized to one exact rational base `r`; the resulting `(p(real(n))/q(real(n)))*r^n` term, with nonzero rational-coefficient `p,q` of degree at most 64, may reconstruct the root limit `abs(r)` internally. Lean separately proves `abs(p(n))^(1/n) -> 1` and `abs(q(n))^(1/n) -> 1`, combines them with `Real.div_rpow`, and then attaches the geometric root. Denominator school-domain guards remain explicit unless the denominator has a conservative global or eventual nonzero proof over naturals. Positive factors such as `real(n)+1` or `real(n)^2+1` are reconstructed with `positivity`; exact nonzero rational geometric factors such as `(-2)^n` are reconstructed with `pow_ne_zero`. Exact rational polynomial factors may instead produce an explicit eventual proof after a concrete threshold: `real(n)-1` uses `n >= 2`, while higher-degree examples such as `real(n)^2-1` also use `n >= 2`. Python chooses a candidate shift using exact rational arithmetic; Lean verifies the translated identity with `ring` and proves the shifted polynomial has one strict sign with `positivity`. Products compose those thresholds with globally nonzero factors. Non-polynomial/sign-oscillating denominators with recurring zeros are not guessed. Non-polynomial numerator/denominator factors still require a cited root-limit theorem. Checkpoint 41 adds the first factorial series family without invoking Stirling: exact nonzero rational `c` and `r` in `c*r^n/factorial(n)` reconstruct the successive norm quotient as `abs(r)/(n+1) -> 0` from `Nat.factorial_succ`, so the quotient-limit ratio test proves summability with no cited limit premise. Checkpoint 42 extends that same recurrence proof to fixed exact shifts `c*r^n/factorial(n+k)` with bounded `k >= 0`, including commuted `k+n` syntax; Lean verifies the factorial-index rearrangement and reconstructs `abs(r)/(n+k+1) -> 0`. Checkpoint 43 adds one exact nonzero rational-coefficient polynomial prefactor: `p(n)*r^n/factorial(n+k)` reconstructs `abs(p(n+1))/abs(p(n)) -> 1` from explicit `Polynomial ℝ` values, multiplies it by `abs(r)/(n+k+1) -> 0`, and reuses the shifted-polynomial eventual-nonzero certificate wherever `p` has early natural roots. Checkpoint 44 extends only that same recurrence family to `(p(n)/q(n))*r^n/factorial(n+k)` with exact nonzero rational-coefficient `p,q` of degree at most 64: Lean separately proves `abs(p(n+1))/abs(p(n)) -> 1` and `abs(q(n))/abs(q(n+1)) -> 1`, proves both current and successor denominator values are nonzero on an explicit tail, then multiplies those limits by the factorial decay to zero. Checkpoint 45 reuses the exact geometric normalization from the ordinary ratio-test path inside that factorial family: products and quotients of nonzero rational powers such as `(1/2)^n*(1/3)^n` or `(1/2)^n/(1/3)^n` are folded to one exact base for search, while Lean independently proves the absolute value of the original geometric expression is `abs(r)^n` with `abs_mul`/`abs_div` and `mul_pow`/`div_pow` before combining it with the factorial recurrence. Zero geometric bases remain outside the automatic path. Checkpoint 46 extends the same family to positive literal powers `factorial(n+k)^m`, `1 <= m <= 64`: Lean checks the powered recurrence with `Nat.factorial_succ` and `mul_pow`, raises the reciprocal tail to the fixed exponent with `Filter.Tendsto.pow`, and reconstructs the ratio contribution `abs(r)/(n+k+1)^m -> 0`. Checkpoint 47 then admits a bounded product of such shifted-factorial leaves in the denominator: Python extracts only exact `(k_i,m_i)` metadata, while Lean checks every submitted factorial recurrence and combines the reciprocal-linear powers to reconstruct `abs(r) / Π_i (n+k_i+1)^m_i -> 0`. Checkpoint 48 adds syntax-only normalization for sequential denominator division, so `a_n/factorial(n)/factorial(n+2)^2` is matched as the same factorial denominator family while the generated Lean proof still targets that original left-associated term. Checkpoint 49 removes the remaining one-factor ordering restriction: `a_n/factorial(n+k)^m/q(n)` and `a_n/q(n)/factorial(n+k)^m` feed the same normalized factorial/polynomial proof path, including exact constant denominator factors, without canonicalizing the submitted theorem. Checkpoint 50 adds the first exact factorial-numerator slice: `c*r^n*factorial(n+k)/factorial(n+m)` with nonzero exact rational `c,r` and fixed nonnegative shifts reconstructs the successive factorial contribution `(n+k+1)/(n+m+1) -> 1` directly from two named `Nat.factorial_succ` recurrences, so the ratio-test limit is `abs(r)` with the usual `<1`, `>1`, and inconclusive `=1` boundaries. Checkpoint 51 composes that cancellation with one exact nonzero rational-coefficient polynomial prefactor `p(n)` of degree at most 64: Lean rebuilds `p(x+1)` and `p(x)` as explicit `Polynomial ℝ` values, proves `abs(p(n+1))/abs(p(n)) -> 1`, reuses the shifted-polynomial eventual-nonzero certificate when `p` has early natural roots, and multiplies that limit by the factorial quotient and geometric factors. Checkpoint 52 adds one exact nonzero rational-coefficient polynomial denominator `q(n)` of degree at most 64 around the same one-up/one-down factorial quotient: Lean also proves `abs(q(n))/abs(q(n+1)) -> 1`, reconstructs eventual nonzero evidence for both `q(n)` and `q(n+1)`, and checks the original submitted quotient before cancellation. Checkpoint 53 then normalizes products/quotients of exact nonzero rational geometric powers around that factorial quotient to one exact base for search while Lean independently proves the absolute value of the original geometric expression is `abs(r)^n`. Checkpoint 54 allows the numerator and denominator shifted factorials to carry the same fixed positive literal power `d <= 64`, including the whole-quotient spelling `(factorial(n+k)/factorial(n+m))^d`; Lean raises the checked linear factorial ratio to `d` with `Filter.Tendsto.pow`. Checkpoint 55 extends that exact recurrence composition to a bounded product of powered shifted-factorial quotients: at most 8 matched quotient factors and total matched power at most 64. Checkpoint 56 adds exact same-shift power cancellation before that matching step, so syntax such as `factorial(n+1)^3 / (factorial(n+1) * factorial(n)^2)` reduces to the already-supported squared quotient family while the Lean artifact still checks the learner's original expression. Common cancelled blocks are retained as neutral quotient evidence in the proof model. Checkpoint 57 then allows balanced residual factorial powers to split exactly across shifts: after same-shift cancellation equal total numerator/denominator powers may be partitioned into exact quotient chunks. Checkpoint 58 opens the first deliberately bounded unequal-power slice: exactly one residual denominator factorial contributes a reciprocal-linear ratio tending to `0` and proves summability, while exactly one residual numerator factorial contributes a linear ratio tending to `+∞`; Lean turns that unbounded ratio into an eventual lower bound `>= 2` and applies `not_summable_of_ratio_norm_eventually_ge`. The learner's original unsimplified factorial expression is still proved directly from `Nat.factorial_succ`, factorial nonzero facts, `field_simp`, and ring normalization. Residual power imbalance of magnitude two or more, zero geometric factors, non-affine factorial arguments, non-polynomial denominators, and broader factorial/Stirling asymptotics remain future work. The next series boundaries are irrational/symbolic p-series exponents, conditional convergence, broader factorial/Stirling families, and broader inequality/limit automation.
