Preferred Codex transport

Let the host Git client carry the agent side.

From a QuickMaths source checkout on the computer running Codex, run this command with your private data-repository URL. Then open the printed loopback URL as the top-level page in the compatible agent browser.

python -m quickmaths.cli agent-bridge --repo https://github.com/YOUR-NAME/quickmaths-sync.git

The workspace connects and pulls automatically. Git credentials stay in Git Credential Manager; JavaScript and WebMCP receive only a short-lived loopback capability. Stop it with Ctrl+C.

Credential and data boundary

Keys never enter the agent page or learning files.

The browser token lives in its session unless you explicitly remember it on that device. The Codex CLI uses the computer's existing Git credentials and sends none of them to JavaScript.

Storage is workspace-wide: each checkpoint includes every QuickMaths learner and educator profile, curriculum, attempt, review, installed pack, map plan, and supplemental educator guidance on this browser origin. QuickMaths refuses a public repository or a token without write access. Limit the token to this one private repository and revoke it immediately if the device is lost.

Deletion: Settings can remove one profile or clear both current checkpoint files after two confirmations. Download a backup first. Deleting current files does not erase older Git commits.

Suggested starting prompt

Give the remote task a strict handoff routine.

You are my QuickMaths learning agent. Keep the QuickMaths Agent Bridge open as the top-level page. Read get_agent_guide, then call sync_from_learner before inspecting progress, recommending work, or tutoring. Use only the registered QuickMaths tools to read or change learning state. Tutor Socratically, never reveal pre-submission answer keys, and preserve my subject and Hard/Open path choices. After any saved feedback, follow-up problem, preference change, or staged lesson set, call publish_agent_checkpoint. If sync reports a conflict, pull the learner again and repeat the intended change from current state; never force stale output over learner work. Recommend a downloadable JSON backup at natural stopping points.

Important limitation

Remote continues a running computer task.

GitHub Pages cannot launch Codex, and the phone does not directly control a static page. The computer must remain online with the Codex task running and Agent Bridge open in its built-in browser. Remote lets you continue that task from your phone; the two checkpoint files let its browser and your learner browser meet safely.
