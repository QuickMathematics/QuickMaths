Preferred Codex transport

Let the host Git client carry the agent side.

From a QuickMaths source checkout on the computer running Codex, run this command with your private data-repository URL. Then open the printed loopback URL as the top-level page in the ChatGPT or Codex in-app browser. An external Firefox, Chrome, Safari, or Edge tab cannot expose the WebMCP tools.

python -m quickmaths.cli agent-bridge --repo https://github.com/YOUR-NAME/quickmaths-sync.git

The workspace connects and pulls automatically. Git credentials stay in Git Credential Manager; JavaScript and WebMCP receive only a short-lived loopback capability. Stop it with Ctrl+C.

Before you leave the computer

Prepare the remote host, then continue from your phone.

First-time agent-in-the-loop setup must be completed on the computer in the ChatGPT or Codex in-app browser. A phone can continue that already-prepared task; it cannot create the first desktop WebMCP session.

  1. 1

    Reduce load safely

    Save your work and close apps you recognize as unnecessary or high-load. In Task Manager, end only processes you recognize and started. Never end Windows, security, driver, Git credential, browser, Codex, or remote-session processes.

  2. 2

    Keep the host awake

    Temporarily set Sleep to Never and disable hibernation for the remote session. Keep a laptop plugged in and ventilated. Restore your normal power settings when you return.

  3. 3

    Prepare lesson packages

    For security, an agent can stage packages only in the desktop QuickMaths session and a human approves each install. If you will work from mobile, install and approve the required packs yourself first, then ask the agent to build the curriculum from that installed library.

Credential and data boundary

Keys never enter the agent page or learning files.

The browser token lives in its session unless you explicitly remember it on that device. The Codex CLI uses the computer's existing Git credentials and sends none of them to JavaScript.

Storage is workspace-wide: each checkpoint includes every QuickMaths learner and educator profile, curriculum, attempt, review, installed pack, map plan, and supplemental educator guidance on this browser origin. QuickMaths refuses a public repository or a token without write access. Limit the token to this one private repository and revoke it immediately if the device is lost.

Deletion: Settings can remove one profile or clear both current checkpoint files after two confirmations. Clearing data keeps the configured storage connection and token; use Disconnect to forget them. Download a backup first. Deleting current files does not erase older Git commits.

Suggested starting prompt

Give the remote task a strict handoff routine.

You are my QuickMaths learning agent. Open the QuickMaths Agent Bridge in the ChatGPT or Codex in-app browser and keep that already-open tab as the top-level page; external browser tabs cannot expose WebMCP tools. First call get_agent_guide with section "summary", then call sync_from_learner before inspecting progress, recommending work, or tutoring. Use only the registered QuickMaths tools to read or change learning state. Tutor Socratically, never reveal pre-submission answer keys, and preserve my subject and Hard/Open path choices. After any saved feedback, follow-up problem, preference change, or staged lesson set, call publish_agent_checkpoint. If sync reports a conflict, pull the learner again and repeat the intended change from current state; never force stale output over learner work. Recommend a downloadable JSON backup at natural stopping points.

Important limitation

Remote continues a running computer task.

GitHub Pages cannot launch Codex, and the phone does not directly control a static page. The computer must remain online and awake with the Codex task running and Agent Bridge open in its built-in browser. Remote lets you continue that task from your phone; the two checkpoint files let its browser and your learner browser meet safely.
